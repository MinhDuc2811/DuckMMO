# Curated background samples and legacy music

Runtime photos are under v3, with originals, author attribution and licenses. Manifest paths
and hashes are verified before render pinning. These are sample photos, not an automatically
selected topic catalog. The user selects a real image/video suitable for the lesson.

v4 contains experimental synthesized instrumentals retained for explicit legacy selection.
**The user rejected these tracks. They are not recommended or selected by default.**
Use licensed, auditioned audio uploads instead. GeneralUser GS license accompanies v4.

Earlier rejected AI images and duplicated music are preserved outside git at
`/workspace/archive/rejected-study-assets/`; original downloadable packs also remain in
`/workspace/english-study-pack*.zip` and `/workspace/english-upbeat-v4.zip`.
No new synthetic music is generated by the app or as part of this integration.

License snapshots in Git have LF endings and trailing spaces normalized; license terms are unchanged. Original byte copies remain in the archived packs.
